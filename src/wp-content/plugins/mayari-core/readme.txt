Plugin funcional del catalogo de Galeria Mayari Rojas.

== Description ==

Registra artistas, colecciones, datos especializados de obras, roles de Coleccionistas y modo catalogo para WooCommerce.

== Changelog ==

= 0.7.0 =
* Tipo editorial Voces sobre Elmar y formulario de autoria, fuente y contexto.
* Separacion estructural entre homenajes y futuras noticias.

= 0.6.0 =
* Formularios editoriales para agenda y archivo multimedia.
* Taxonomia tematica para galerias y metadatos estructurados de eventos.

= 0.5.1 =
* Compatibilidad de sanitizadores de metadatos de terminos con los cuatro argumentos de WordPress.

= 0.5.0 =
* Migracion ejecutable protegida por confirmacion explicita.
* Snapshot por obra antes de cada escritura e identificador de corrida.
* Comando de rollback que restaura metadatos, taxonomias, SKU e imagen.
* Procesamiento reanudable y auditoria posterior a la migracion.

= 0.4.0 =
* Comando de simulacion de migracion sin operaciones de escritura.
* Mapeo preliminar de artistas, colecciones y disciplinas heredadas.
* Parsers conservadores de ano, medidas, tecnica, soporte y materiales.
* Informes resumidos, JSON y CSV para revisar excepciones.

= 0.3.0 =
* Formularios editoriales enriquecidos para Artistas y Colecciones.
* Selector de retrato y portada desde la Biblioteca de medios.
* Perfil especial de Elmar Rojas y prioridad editorial de artistas.
* Relacion de colecciones con artistas, periodo, texto curatorial y visibilidad.
* Capacidades especificas para que el Gestor de galeria administre taxonomias.

= 0.2.0 =
* Formulario administrativo de ficha artistica por secciones.
* Campos condicionales por disciplina.
* Guardado seguro con nonce, capacidades y sanitizacion.
* Columnas y filtros de catalogo en Productos.
* Aviso de ficha incompleta sin bloquear borradores heredados.

= 0.1.0 =
* Estructura inicial del plugin.
* Roles Coleccionista y Gestor de galeria.
* Taxonomias de artistas, colecciones, tecnicas, soportes y materiales.
* Tipos de contenido de Agenda y Archivo multimedia.
* Esquemas de metadatos de obra.
* Proteccion inicial de visibilidad y precios.
* Modo catalogo de WooCommerce.
