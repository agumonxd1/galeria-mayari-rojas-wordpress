# Flujo administrativo: Artistas y Colecciones

## Artistas

En **Productos > Artistas**, el Gestor de galeria puede crear o editar un artista con:

- nombre, slug y descripcion breve nativos de WordPress;
- retrato vertical y portada panoramica desde la Biblioteca de medios;
- biografia e historia/trayectoria;
- prioridad y orden editorial;
- presentacion estandar o perfil especial de Elmar Rojas.

El perfil especial modifica la futura presentacion del tema, pero no crea un inventario separado. Las obras continúan relacionadas con el mismo termino de artista.

## Colecciones

En **Productos > Colecciones**, el Gestor de galeria puede registrar:

- titulo, subtitulo y slug;
- periodo inicial y final;
- portada y texto curatorial;
- uno o varios artistas relacionados;
- visibilidad publica, para coleccionistas u oculta;
- orden editorial.

La visibilidad de una coleccion no reemplaza la visibilidad individual de cada obra. Al construir el tema, ambos controles deben cumplirse para publicar contenido.

## Permisos

El rol **Gestor de galeria** administra artistas, colecciones y taxonomias tecnicas mediante capacidades propias. No recibe permisos para plugins, temas, configuracion ni usuarios administradores.

## Criterios editoriales

- Usar retratos consistentes y portadas de alta resolucion.
- Reservar el perfil especial exclusivamente para Elmar Rojas.
- Mantener los anos vacios cuando la fecha no sea comprobable.
- Marcar como oculta una coleccion incompleta durante su preparacion.
